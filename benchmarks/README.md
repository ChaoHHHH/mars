# NMOS / PMOS 标准数值案例

两套独立、确定性的 stress–recovery 回归案例。固定器件、缺陷、初始平衡、波形、求解精度、输出格式及验收标准；改动求解器后可重复运行比较。

这些是为检查物理方向与求解流程设计的合成参数，不是实验拟合或具体缺陷的材料数据库参数。速率使用当前源码的双能带通道、DFT归一化及FD势垒近似。

|参数|NMOS / SiO2|PMOS / SiO2 + HfO2|
|---|---|---|
|Si体区|p型，Na=1e23 m^-3|n型，Nd=1e23 m^-3|
|绝缘层，从沟道到栅极|3 nm SiO2，eps_r=3.9|1 nm SiO2 + 2 nm HfO2，eps_r=3.9/25|
|栅功函数|4.6 eV|4.6 eV|
|缺陷类型|acceptor|donor|
|缺陷区域|0.5–2.5 nm|1–3 nm，仅HfO2|
|Nt|3e24 m^-3|1e25 m^-3|
|转变能级，真空参考|−4.6 eV|−4.8 eV|
|能级Gaussian标准差|0.12 eV|0.12 eV|
|Er12 / Er21|0.8 / 0.8 eV，均无展宽|相同|
|VBM / CBM耦合前因子|3e−6 / 3e−6 eV|相同|
|两通道距离衰减系数|1e9 m^-1|相同|
|预平衡偏压|−2 V|+2 V|
|应力 / 恢复偏压|+2 / −2 V|−2 / +2 V|
|温度、持续时间|300 K；每阶段1000 s，3周期|相同|

完整设置分别见两个 JSON。Et统一为转变能级；n_DFT_m3=1e27，不使用缺陷浓度归一化因子。为减小计算量，每套171个采样点，不使用随机采样。此处以单一重组能隔离能级/空间分布效应；不覆盖重组能展宽的所有情况。

## 运行

在仓库根目录、已安装 requirements.txt 依赖的环境中：

```bash
python -m benchmarks.run
python -m benchmarks.run --case nmos_sio2
python -m benchmarks.run --case pmos_sio2_hfo2
```

默认输出 `figs/benchmarks/<case>/`，也可用 `--output <目录>` 指定。运行无GUI、不调用show、不导入有构造副作用的run。每套自动运行基准精度和细化精度，并用np.testing检查验收条件。

输出包括：

- stress_recovery.png：Vg、带符号阈值漂移、平均电子占据，三行六阶段。
- history.csv / refined_history.csv：保留真实累计时间、阶段时间、自适应dt、偏压、环境表面势、占据、相对预平衡的漂移。
- pre_equilibrium.npz：初始x、权重、f和局部转变能级。
- parameters.json：此次完整输入；summary.json：计算结果和验收摘要。

图上每阶段按实际计算采样点序号等距排列，中央标记阶段真实时长；不是线性时间轴。计算与收敛比较始终使用真实秒数。纵轴为线性、有正负号的mV，不取绝对值。history中的psi_s是推进时使用的环境表面势，沿用advance接口语义，并非每个历史时刻重新自洽的快照。

## 物理预期与基准结果

漂移定义为当前缺陷电荷贡献减去预平衡参考贡献：

$$
\Delta V_{th}(t)=V_{th}(t)-V_{th}(\mathrm{pre}).
$$

NMOS正偏压下acceptor捕获电子，电荷变负，阈值向正方向漂移；反向偏压恢复释放电子。PMOS负偏压下donor失去电子，电荷变正，阈值向负方向漂移；反向偏压恢复捕获电子。恢复特意使用反向偏压，不能解读为零偏压恢复实验。预平衡是静态平衡，不代表经历有限预处理时间。

当前电压预检查求解器的结果（速率保持现有 DFT 归一化定义）：

|量|NMOS|PMOS|
|---|---:|---:|
|无缺陷Vth0|+0.551219 V|−0.484679 V|
|首次应力结束漂移|+41.7544 mV|−14.4457 mV|
|首次恢复结束剩余漂移|+0.282542 mV|约0 mV|
|基准/细化整条曲线最大差异|0.05591 mV|0.07609 mV|

验收：有效数值有限、平均占据在[0,1]；首次应力漂移方向正确且幅度大于10mV；首次恢复剩余绝对幅度低于应力幅度25%；基准/细化在相同真实时刻插值比较，整条曲线最大差异低于0.5mV。插值差异包含输出时间离散误差；不是完整数学误差上界。

基准设置：dt_max=10s，电压阈值1e−4V；细化设置：dt_max=2.5s，电压阈值1e−5V。advance 已删除占据预算参数，改为接受步之前试算电压变化，超限时刷新环境或缩步重试。此次比较同时收紧最大步长与电压阈值，不是单因素扫描，也不证明空间/能量网格收敛。

当前实现的回归仍与既有固定时刻参考值比较，绝对容差0.1mV。原占据预算循环已被移除；旧探索中预算0.002的推进卡顿不再对应当前算法。

源码和JSON可加入Git；figs按仓库既有规则忽略，可通过上述命令再生成。运行器与输出格式保持原接口，求解器采用电压预检查。
